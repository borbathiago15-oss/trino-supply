## 1. Logo Oficial

| Asset | Arquivo | Dimensões | Uso |
|-------|---------|-----------|-----|
| DS-ASSET-001 | `assets/logo/trino-supply-logo-login.png` | 1448×1086 PNG | Área de login e superfícies escuras |

## 2. Descrição da Marca

* **Símbolo:** hexágono metálico (prata/cinza) com seta vermelha em movimento — representa fluxo de suprimentos e direção.
* **Wordmark:** `TRINO` em branco, `SUPPLY` em cinza, separados por linha vertical fina.
* **Acento:** linha vermelha sob o wordmark.
* **Tagline:** "Gestão Inteligente de Suprimentos".
* **Fundo oficial:** azul-marinho profundo.

## 3. Paleta Derivada (referência para o Design System)

| Papel | Cor | Uso |
|-------|-----|-----|
| Background primário | Azul-marinho (do asset) | Login, headers escuros |
| Accent / ação | Vermelho (do símbolo) | CTAs, destaques, alertas de ação |
| Neutro claro | Branco | Texto primário sobre fundo escuro |
| Neutro médio | Cinza (do wordmark SUPPLY) | Texto secundário |
| Metálico | Prata/cinza gradiente | Elementos de marca (não UI) |

> Tokens exatos (hex) serão extraídos e formalizados no documento de Design Tokens do Design System (planejado).

## 4. Regras de Uso

1. Não alterar cores, proporções ou orientação do símbolo.
2. Sobre fundos claros, utilizar versão adaptada (a produzir — atualmente só existe a versão para fundo escuro).
3. A área de login do produto deve usar DS-ASSET-001 como asset principal.
4. Novos assets de marca exigem registro no Document Registry (GOV-002).
