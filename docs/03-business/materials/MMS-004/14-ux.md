# 1. Princípios (IV-UX)
- IV-UX-001 Operação rápida por documento; ação em uma etapa; **scanner-friendly** (preparação para código de barras).
- IV-UX-002 Saldo é leitura; nenhuma tela permite editar saldo (ADR-009) — só documentos.
- IV-UX-003 Captura em unidade de compra com conversão visível para a base (ADR-013).
- IV-UX-004 Itens sem permissão ocultados (IV-BR-100); Requester nunca vê a visão do almoxarifado.
- IV-UX-005 WCAG 2.1 AA; contraste e foco (DS-001).

# 2. Personas × Workspace
| Persona | Workspace | Foco |
|---------|-----------|------|
| Almoxarife | Warehouse | Fila de atendimento, recebimentos, movimentações, inventário, endereçamento |
| Supervisor | Warehouse+ | Aprovação de ajustes, locais |
| Gerente | Management | Posição, KPIs, alertas, sugestões de reposição |

# 3. Telas (IV-SCR)
- IV-SCR-01 Posição de estoque (saldo total/disponível/reservado por item×local)
- IV-SCR-02 Registro de movimentação (entrada/saída/transferência) com captura de UoM
- IV-SCR-03 Reservas (ativas, a vencer)
- IV-SCR-04 Ajustes (registrar/aprovar) com saldo anterior/posterior
- IV-SCR-05 Inventário (abertura, contagem, divergências, fechamento)
- IV-SCR-06 Endereçamento (estrutura de locais)
- IV-SCR-07 Alertas
- IV-SCR-08 Fila de sugestões de reposição (confirmar/descartar)

# 4. Padrões de Interação
Confirmação de movimento em uma etapa; seleção de tamanho para item com grade; conversão de UoM exibida (informado × base × fator); chips de status; drill-down do KPI ao documento.

# 5. Acessibilidade/Responsividade/i18n
WCAG 2.1 AA; tablet no almoxarifado; i18n pt-BR/en-US (Foundation).
